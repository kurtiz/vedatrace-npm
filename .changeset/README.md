# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version and publish your code. You can
find the full documentation for it [in our repository](https://github.com/changesets/changesets)

We have a quick list of common questions to get you started engaging with this project in
[our FAQ](https://github.com/changesets/changesets/blob/main/docs/FAQ.md)

The important folders in this project are:

- `.changeset` - Contains the configuration and changeset files
- `CHANGELOG.md` - Automatically generated changelog

## Usage

### Adding a changeset

When making changes that should trigger a version bump:

```bash
bun changeset
```

This will prompt you to:
1. Select the type of change (patch, minor, major)
2. Write a summary of the change

The changeset file will be created and should be committed with your changes.

### Release Flow

1. Merge PRs with changeset files to `main`
2. GitHub Actions creates a "Version Packages" PR automatically
3. Review and merge the "Version Packages" PR
4. GitHub Actions publishes to npm automatically

### Pre-releases (Beta/Alpha)

To publish pre-release versions:

```bash
# Enter pre-release mode for beta
bun changeset pre enter beta

# Make changes and add changesets as normal
bun changeset

# Version and publish
bun changeset version
bun changeset publish

# Exit pre-release mode when ready for stable
bun changeset pre exit
```
